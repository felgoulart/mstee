Configuração feita uma única vez (ou quando a chave do GitHub expirar). A chave fica guardada no site criptografada com o usuário e a senha definidos abaixo.

Como obter a chave de acesso?
  1. Entre no GitHub com a conta dona do repositório e abra Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Dê um nome (ex.: Admin MStee) e escolha a validade.
  3. Em Repository access, selecione Only select repositories e marque mstee.
  4. Em Permissions → Repository permissions, defina Contents como Read and write.
  5. Clique em Generate token, copie o código e cole acima.
