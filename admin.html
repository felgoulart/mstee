Área do administrador

Entre com a chave de acesso (token do GitHub) para editar o ranking e os aniversariantes.

Como obter a chave de acesso?
  1. Entre no GitHub com a conta que administra o site e abra Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Dê um nome (ex.: Admin MStee) e escolha a validade.
  3. Em Repository access, selecione Only select repositories e marque o repositório do site.
  4. Em Permissions → Repository permissions, defina Contents como Read and write.
  5. Clique em Generate token, copie o código e cole acima.

A chave fica salva apenas neste navegador. Nunca compartilhe a chave.
